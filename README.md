# ConnectMessenger

Full-stack real-time messaging application prototype with a React/Vite frontend and FastAPI backend.

## Focus

- Real-time messaging and calling foundations
- React interface with reusable components
- FastAPI backend and API documentation
- Authentication and database integration concepts
- Docker-oriented local development

## Status

Prototype showcase. Dependency folders, logs, local databases, environment files, and generated test artifacts are intentionally excluded until a dedicated source-cleanup pass is complete.
